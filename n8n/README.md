# n8n

- `workflows/` — export do workflow (n8n → ⋯ → Download). **Credenciais não vão no export**; não commite arquivos de credencial.
- `prompts/` — prompts usados no nó de IA. Ao alterar no n8n, atualize aqui também (histórico de mudanças do prompt).

Guia completo de configuração: ver `docs/guia-n8n.md`.
