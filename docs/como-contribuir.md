# Como contribuir

- Notas novas chegam pelo fluxo automático; prefira **Ajustar** no Slack antes de aprovar.
- Correção manual: edite o arquivo direto no GitHub/Obsidian e commite com `docs(dsmm): DSMM-xxx — ajuste`.
- Mantenha o frontmatter (o índice depende de `ticket`, `titulo`, `sistema`, `tipo`, `resolvido_em`).
- Nunca inclua dados de cliente (CPF/CNPJ, cartão, e-mail, tokens).
- Nota criada à mão: copie `templates/nota-dsmm.md` para `dsmm/<sistema>/DSMM-xxx.md`.
